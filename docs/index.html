Core Capabilities

Designed for Modern Group Workflows

From weekend sports leagues to team decision making, PulsePoll brings clarity and speed to group events.

🔑

6-Character Join Codes

No messy account invites or lost links. Share a clean 6-character short code (e.g. SOC5V5) to instantly discover and vote on any device.

Release Engineering & Operations

Production Deployment & Manual Setup

Complete end-to-end instructions, manual console setup, and automation scripts for deploying PulsePoll to Google Play Store and Firebase.

🔥

1. Firebase & Auth Setup

1. Create a Firebase project on the Spark Free Tier ($0/mo).
2. Register package com.aistudio.pollpulse.qxrvlz.
3. Enable Google Sign-In & Cloud Firestore.
4. Place google-services.json into /app.

🔐

2. Release Keystore & SHA-1

1. Run bash scripts/generate-release-keystore.sh.
2. Copy SHA-1 & SHA-256 certificate fingerprints.
3. Add fingerprints in Firebase Console ➔ Project Settings.
4. Configure signing in gradle.properties.

📦

3. Play Store Rollout (.AAB)

1. Run bash scripts/build-release.sh.
2. Locate bundle at app-release.aab.
3. Upload to Google Play Console Internal Testing track.
4. Promote to Closed Beta and Production!
