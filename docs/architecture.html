Background Coroutine pushes the vote document to Cloud Firestore (polls/{id}/votes) ➔ 5. Cloud SnapshotListeners broadcast the new tallies in real-time to other participants.

💾

1. Hybrid Storage Engine

Room SQLite + Cloud Firestore

Instead of relying exclusively on the network, LivePulse uses a two-tier cache:

  • 📦
    Local SQLite Cache (Room): Reads and initial writes hit the on-device SQLite database first. Guarantees 0ms UI response time and 100% offline functionality.
  • ☁️
    Cloud Firestore Relay: Asynchronous background sync sends updates to Firebase. Realtime WebSocket snapshot listeners sync results between multiple phones without needing a custom server backend.

3. Cost Model & Security

$0 / month Spark Tier & ACL Rules

Engineered for zero maintenance overhead and low costs:

  • 📊
    50,000 Reads / Day Free: Because local users read from Room SQLite, cloud document reads are minimized, staying well within Firebase's free allowance.
  • 🔒
    Granular Security Rules: firestore.rules ensures only the poll creator can delete or close polls, while public voters can only append their own vote documents.
PollRepository.kt (Clean Architecture) KOTLIN COROUTINES + FLOW 
// Real-time stream: Emits SQLite cache immediately, then updates from Cloud WebSocket
fun observePoll(pollId: String): Flow<PollWithDetails?> = callbackFlow {
    // 1. Emit local Room cache instantly (0ms latency, 100% offline capable)
    val localData = pollDao.getPollWithDetails(pollId)
    trySend(localData)

    // 2. Attach Firestore Realtime SnapshotListener
    val registration = firestore.collection("polls").document(pollId)
        .addSnapshotListener { snapshot, error ->
            if (error != null || snapshot == null) return@addSnapshotListener
            val remotePoll = snapshot.toObject(PollEntity::class.java) ?: return@addSnapshotListener
            
            // 3. Upsert to Room SQLite, automatically re-triggering StateFlow for UI
            coroutineScope.launch(Dispatchers.IO) {
                pollDao.upsertPoll(remotePoll)
            }
        }

    awaitClose { registration.remove() }
}
