SPEC-001 — Vote change replaces the ballot

behaviorvotingstatus: verified priority: p1 bug_ref: KB-04 verified_scope: web client on local Firestore-emulator loop

Given

  • A poll is open and the voter has already submitted a ballot

When

  • The voter changes their selection and submits again

Then

  • Exactly one votes/{voterId} ballot doc exists in Firestore
  • The total vote count is unchanged by the swap
  • The voter's legacy per-option docs, if any, are superseded

SPEC-003 — Manual poll close syncs live to all clients

behaviorsyncstatus: implemented priority: p2 bug_ref: KB-06

Given

  • A poll is open and at least one web client is watching the results

When

  • The creator taps Close Voting Now on the app

Then

  • The poll doc gains isClosed=true via merge write
  • Web clients see the Closed badge and lose the vote card without a reload
  • Other devices learn the close through the same snapshot listener
